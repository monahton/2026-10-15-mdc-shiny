Python 3 and Visual Studio Code (VS Code)

In this workshop, we will use Python 3, a widely used programming language for data analysis, visualization, automation, and scientific computing.

We will write and run Python code using Visual Studio Code (VS Code), a free, lightweight code editor available for Windows, macOS, and Linux. VS Code supports Python development through extensions, including code completion, debugging, and interactive notebooks.

Before the workshop: Please install both Python 3 and VS Code, then follow the instructions below to configure your Python environment.

  • Windows
  • macOS
  • Linux / WSL

1. Install Python 3

  1. Visit the official Python download page .
  2. Download the recommended Python installer or Python install manager for Windows.
  3. Run the downloaded file and follow the installation instructions. If using the traditional installer, select "Add Python to PATH" when the option is available.
  4. Make sure a Python 3 runtime is installed.

2. Verify Python installation

Open Command Prompt or PowerShell and run: 

python --version

Alternatively, run: 

py --version

You should see a Python 3 version number.

Note: If Python is not recognized, close and reopen your terminal. Check that Python was installed correctly and is accessible from the command line.

3. Install VS Code

  1. Download VS Code from the official VS Code website .
  2. Select the Windows installer and follow the installation instructions.
  3. Launch VS Code after installation.

4. Install the Python extension

  1. Open VS Code.
  2. Open the Extensions panel using Ctrl + Shift + X.
  3. Search for Python and install the extension published by Microsoft.
  4. Open the Command Palette using Ctrl + Shift + P.
  5. Search for Python: Select Interpreter and choose your installed Python 3 version.

1. Install Python 3

  1. Visit the official Python download page .
  2. Download the recommended Python 3 .pkg installer for macOS.
  3. Open the downloaded file and follow the installation instructions.

2. Verify Python installation

Open the Terminal application and run: 

python3 --version

You should see a Python 3 version number.

Note: On macOS, use python3 rather than python when running Python from the terminal.

3. Install VS Code

  1. Visit the VS Code download page .
  2. Download the macOS version appropriate for your Mac.
  3. Open the downloaded archive and move Visual Studio Code.app to your Applications folder.
  4. Launch VS Code.

4. Install the Python extension

  1. Open VS Code.
  2. Open the Extensions panel using Cmd + Shift + X.
  3. Search for Python and install the extension published by Microsoft.
  4. Open the Command Palette using Cmd + Shift + P.
  5. Search for Python: Select Interpreter and select your installed Python 3 version.

1. Install Python 3

Python 3 is often already installed on Linux. Open a terminal and check: 

python3 --version

If Python 3 is not installed, use your Linux distribution's package manager. For Ubuntu, Debian, or Ubuntu on WSL2, run: 

# Update package lists
sudo apt update

# Install Python 3, pip, and virtual environment support
sudo apt install -y python3 python3-pip python3-venv
Note: Run these commands in your Linux terminal. Lines beginning with # are comments and do not need to be executed. Other Linux distributions may require different installation commands.

2. Verify Python installation

Run:

python3 --version
python3 -m pip --version

These commands should display your Python 3 and pip versions.

3. Install VS Code

For Linux desktop users:

  1. Visit the VS Code download page .
  2. Download the package appropriate for your Linux distribution, such as .deb for Ubuntu/Debian or .rpm for Fedora.
  3. Install the downloaded package using your software manager or terminal.

For Ubuntu/Debian, after downloading the .deb file, you can install it with: 

# Run from the directory containing the downloaded file
sudo apt install ./code_*.deb

For Windows users working with WSL2:

  1. Install VS Code for Windows . You do not need to install the Linux desktop version inside WSL.
  2. Open VS Code in Windows.
  3. Install the WSL extension published by Microsoft.
  4. Open your WSL terminal, navigate to your project directory, and run: 
code .

This opens your current WSL directory in VS Code, connected to your Linux environment.

WSL users: Install Python inside your WSL distribution and use the Python interpreter from WSL. See the official VS Code WSL guide for more information.

4. Install the Python extension

  1. Open VS Code.
  2. Open the Extensions panel using Ctrl + Shift + X.
  3. Search for Python and install the extension published by Microsoft. If using WSL, install it in your WSL environment.
  4. Open the Command Palette using Ctrl + Shift + P.
  5. Select Python: Select Interpreter and choose the Python 3 interpreter.

Verify your setup

Once Python 3 and VS Code are installed:

  1. Open VS Code.
  2. Create a new file named hello.py.
  3. Enter the following Python code:
print("Hello, Python!")
print("My Python environment is ready!")
  1. Save the file and make sure the correct Python interpreter is selected.
  2. Click Run Python File (the play button in the upper-right corner of the editor).

You should see:

Hello, Python!
My Python environment is ready!
You're ready for the workshop! If your script runs successfully, Python 3 and VS Code are correctly configured.
